# AndesBev · Dashboard de diagnóstico

Diagnóstico de la cadena de suministro de AndesBev SpA (piloto Coquimbo–La Serena). Grupo 6 · DataRoute Lab.

Sitio: https://ruulitos.github.io/andesbev-dashboard-publico/

Los identificadores de cliente están seudonimizados (`CL-…`) y las coordenadas redondeadas a 3 decimales. Las cifras agregadas no cambian.
El sitio se genera con `python build_dashboard.py --anonimizar` desde el proyecto de análisis (privado).
